Reading the per-domain diagrams

Inside a domain, line colour is the delete rule, because that is the thing most likely to surprise you. Red is ON DELETE CASCADE — the child dies with its parent. Green is ON DELETE RESTRICT — the parent cannot be removed while the child exists. Grey is SET NULL or NO ACTION. The number in the corner of each box is its column count.
